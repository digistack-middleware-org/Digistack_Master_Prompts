## Starting a New Session? Read This First

Before loading any Part folder or asking a question:

1. Open **`SESSION_STATE.md`** — tells you which folder is currently active.
2. Open that folder's own **`README.md`** — has full status, AI Resume
   Context, and exactly what to upload for a fresh chat (see its "What a
   Fresh Chat Needs" checklist).

This project has 28+ documents and several very large files. Loading
everything every session risks hitting token limits before real work
starts. These files exist to scope every session down to only what's
needed — trust the "Do Not Load" lists rather than defaulting to
"just load everything."
