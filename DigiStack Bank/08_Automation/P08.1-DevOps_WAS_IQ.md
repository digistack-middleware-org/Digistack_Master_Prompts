Purpose
-------
Same discipline as P03.2/P07.1, one tier up: a permanent, fully-worked
interview reference book derived entirely from P08 — every question,
scenario, troubleshooting case, runbook, and mock interview must map back
to a specific version/component actually built in that Part. P08 covers
Source Control/Branching, CI/CD, Infrastructure-as-Code, Deployment
Automation, and the End-to-End pipeline capstone — this file is the
interview material for exactly that, nothing else.

Boundary Note (P08.1 vs. P03.2 / P07.1)
------------------------------------------------
- P03.2 — the application itself (CBS, Fund Transfer, channel simulators).
- P07.1 — operating/recovering/scaling/migrating that application
  (observability, HA/DR, multi-region, platform migration).
- P08.1 — how the application and platform get *built, tested, and
  deployed* (Git workflow, Jenkins pipeline, Ansible/wsadmin automation,
  deployment automation, region-aware pipeline governance). A question
  about Jenkins pipeline stages belongs here; a question about what the
  pipeline deploys belongs in P03.2/P07.1.

Deployment Model
------------------
Zero new banking functionality, zero new infrastructure — documentation/
reference artifacts only, same as every prior Interview Part. Produced
sprint by sprint, one chapter's worth of content at a time, in the agreed
format: short spoken-style answer + why-it's-asked + implementation
reference + architecture tie-in + real example + follow-ups + mistakes +
best practices.

Placement Note
------------------
Suffix Part, same mechanism as P03.1/P03.2/P07.1. Sits between P08 and P09
in reading order (P08 → P08.1 → P09). No version numbers (v1–v78) are
touched; this produces no deployables.

Prerequisite
------------------
P08 Completion Checkpoint satisfied — the commit-to-production-ready
pipeline (v49–v53) is live and region-aware across India/Singapore/Dubai.
Assumes the candidate actually built P08, not merely read about it, same
standing assumption every prior Interview Part makes.

Version 2 — Chapter 2: Real Production Scenarios
------------------------------------------------------------
Objective: Realistic production scenarios built from P08 components
(GitHub branch protection, Jenkins, Nexus, Ansible, /wsadmin-lib,
region-partitioned inventory).

Sprint 1 — Source Control Scenarios (merge without review, accidental
force-push to main, hotfix branch bypassing pipeline)
Sprint 2 — CI/CD Scenarios (Nexus artifact mismatch across environments,
credential leak in Jenkinsfile, stuck manual approval gate)
Sprint 3 — IaC Scenarios (non-idempotent playbook drifting a node,

Sprint 4 — Deployment Automation Scenarios (health-check false green,
automated rollback triggering incorrectly, plugin regen failing silently)
Sprint 5 — Pipeline Governance Scenarios (Singapore validation failure
not halting Dubai, notification not firing on failure)
Sprint 6 — Capstone: Combined pipeline failure during a live multi-region
rollout

Deliverable: Full scenario bank, each tied to a specific component and a
specific P08 version.

Version 3 — Chapter 3: Production Troubleshooting
------------------------------------------------------------
Objective: Full troubleshooting cases in the fixed shape: Production
Problem → Business Impact → Symptoms → Request Flow → Components
Involved → Logs to Check → Commands to Execute → Investigation Process →
Root Cause → Resolution → Prevention → Lessons Learned.

Sprint 1 — Git/Branch Protection Failures (protected branch bypassed,
broken PR gate)
Sprint 2 — Jenkins/Nexus Failures (build failure, artifact checksum
mismatch across environments, credential exposure in console log)
Sprint 3 — Ansible/wsadmin Failures (playbook non-idempotency discovered
in production, wrong region targeted, drift vs. SOE01 golden image)
Sprint 4 — Deployment Automation Failures (automated rollback loop,
health check gating a genuinely healthy deploy, session validation
false failure)
Sprint 5 — Region-Sequencing Failures (one region's failure not halting
the next, notification delivery failure)
Sprint 6 — Capstone: Multi-stage pipeline failure requiring rollback
across two regions

Deliverable: Full troubleshooting case bank, cross-referenced against
P08's own Completion Checklist items.
